# 📱 phone-demo-part3-techbroz

**GitHub Phone se — Part 3: Issues aur Pull Requests** ka demo repo (Tech Bro Z).

Is repo mein sab kuch phone se samjhaya gaya hai:

- 🐞 **Issue #1** banaya: footer mein saal galat tha (2025) — label `bug`
- ✨ **Issue #2** banaya: dark mode button chahiye — label `enhancement` (aapka homework 😉)
- 🌿 Naya branch `fix-footer-year` banaya
- ✏️ Branch pe `index.html` edit karke commit kiya
- 🔀 **Pull Request** khola, body mein `Fixes #1` likha
- 👀 PR ko review kiya (Files changed dekh ke comment)
- ✅ PR **merge** kiya → Issue #1 apne aap close ho gaya!
